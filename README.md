# 🐒 Monkey Explorer

Welcome to **Monkey Explorer** – a fun and educational project all about monkeys! This project demonstrates basic coding principles while introducing some fascinating facts about our primate cousins.

## 📚 Overview

This project includes:
- Monkey facts and data
- A basic script to interact with monkey information
- A sample visualization of monkey habitats
- Opportunities to expand into machine learning or web visualization
